## GitHub Pages

Use these settings in GitHub:

1. Open your repository settings.
2. Go to Pages.
3. Set Source to Deploy from branch.
4. Choose branch: main
5. Choose folder: /root
6. Save and publish.

Your published site will be available at the URL shown in the GitHub Pages section.

## Local preview

This repository includes a simple Codespaces-ready static server setup. The page can be previewed locally with:

python3 -m http.server 8000

Then open http://localhost:8000 in your browser.
